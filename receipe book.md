## purpose
I want to create a recipe book app that will store all my wife's recipes that we will upload. I want her to be able to search through recipes by what is healthy, costly, quick, etc. in an efficient manner when she meal preps on Saturdays evenings.

## capabilities
I want it to be able to do the following:
- store recipes including the following:
	- ingredients
	- instructions
	- time
- assess cost
	- this doesn't have to be precise it can be rough (\$ or \$\$ or \$\$\$)
	- this step may necessitate the building of an agent for this app
- assess health
	- what are the health highlights? health/not? good for heart? good for palette cleansing? etc.
- I want to be able to search with keywords against the title
- I want there to be a multi-dropdown selection box to search by multiple ingredients
- I want to be able to filter and sort by health (simply healthy or not), cost, and time to make
- I want to be able to select which recipes to use for the week and for these ingredients to automatically be added to my grocery shopper page.
- Possible future state:
	- I want to be able to ask the agent in plain text to construct a recipe given certain health, cost, ingredients, and time parameters.
